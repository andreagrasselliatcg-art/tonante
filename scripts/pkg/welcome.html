Tonante

three oscillator monosynth · Tune Talks

Questo programma installa lo strumento Tonante in formato:

  • Audio Unit per Logic Pro e GarageBand
  • VST3 per Ableton Live

Con Personalizza puoi scegliere quale formato installare.

Dopo l'installazione:
• Logic Pro: nuova traccia Strumento software → AU Instruments → Tune Talks → Tonante
• Ableton Live: Impostazioni → Plug-in → attiva "Use VST3 Plug-in System Folders" → Rescan, poi Plug-ins → VST3 → Tune Talks → Tonante
